# 📖 About

APEX is my robotics platform that I am building from scratch to learn robotics, embedded systems, electronics, programming, and artificial intelligence.

The goal of this project is to build a fully autonomous robot step by step while documenting every stage of development.

This repository contains all hardware documentation, source code, progress logs, images, and future upgrades.

# 🛠 Hardware

Current hardware:

- ESP32 Dev Module
- TB6612FNG Motor Driver
- 2 × DC Gear Motors
- Chassis
- Battery Pack
- Wheels
- Power Switch

More components will be added as the project grows.
