# Session 01 – ESP32 First Blink

## Objective
Set up the ESP32 development environment and upload the first Blink program.

## Hardware Used
- ESP32 Dev Module
- USB Cable
- HP Victus Laptop

## Software Used
- Arduino IDE 2.3.10
- Silicon Labs CP210x Driver

## Result
✅ Driver installed successfully.

✅ ESP32 detected.

✅ COM8 configured.

✅ Blink sketch compiled successfully.

✅ Program uploaded successfully.

✅ On-board LED blinking.

---

## Skills Learned

- Installing ESP32 USB drivers
- Configuring Arduino IDE
- Selecting the correct board
- Selecting the correct COM port
- Uploading code to ESP32
- Basic Arduino programming
